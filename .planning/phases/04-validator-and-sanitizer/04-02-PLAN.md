func Sanitize(cfg *ir.ZoningConfig, fosVersion string) *ir.ZoningConfig

The function MUST apply operations in this MANDATORY order:
1. Char replacement (invalid chars to `_`)
2. Truncation (> 63 chars to 63 chars)
3. Collision detection and disambiguation (`_2`, `_3` suffixes)
4. Cross-reference updates (zone member alias values, zoneset zone names)
5. Map key rebuilding

**Implementation details:**

**Step 2a: Select regex based on fosVersion.**
If `fosVersion == "8.1+"`, use `reInvalidExtended`. Otherwise use `reInvalidConservative`.

**Step 2b: Process all three entity types (aliases, zones, zoneconfigs) through a common rename pipeline.**

For each entity type, build a rename map `map[string]string` (oldName -> newName):

1. For each entity, apply char replacement: `re.ReplaceAllString(name, "_")`. If the result differs from the original, append a warning: `fmt.Sprintf("alias %q: invalid characters replaced -> %q", original, sanitized)` (use "zone" or "cfg" as the entity label as appropriate).

2. After char replacement, apply truncation: if `len(name) > 63`, truncate to `name[:63]` and append warning: `fmt.Sprintf("alias %q truncated to 63 characters: %q -> %q", original, original, truncated)`.

3. After both passes complete for an entity type, detect collisions: build `map[sanitized][]originalName`. For any group with len > 1, `sort.Strings(originals)` for deterministic order. First entry keeps the sanitized name. Subsequent entries get `_2`, `_3`, etc. suffix. CRITICAL: if adding suffix `_N` would make the name exceed 63 chars, truncate the base BEFORE appending the suffix: `base = sanitized[:63-len(suffix)]` then `newName = base + suffix`. Append collision warning: `fmt.Sprintf("collision: names %v all sanitize to %q -- disambiguated", originals, sanitized)`.

**Step 2c: Rebuild maps with new keys.**

For aliases: create `newAliases := make(map[string]*ir.Alias, len(cfg.Aliases))`. Range over original map, look up rename, update `.Name`, insert with new key.

For zones: create `newZones` map. For each zone, get the renamed name from the zone rename map. Update `.Name`. Compute new key: if `cfg.SourceFormat == "mds-nxos"`, key = `fmt.Sprintf("%s@vsan%d", newName, zone.VSAN)`. Otherwise key = `newName`. Insert into new map.

For zoneconfigs: same pattern as zones (MDS uses composite key, Brocade uses plain name).

**Step 2d: Update cross-references using the rename maps.**

Build alias rename map (oldName -> newName). Iterate ALL zone members across ALL zones: if `member.Type == "alias"` and `aliasRenameMap[member.Value]` exists, update `member.Value` to the new name.

Build zone rename map (oldName -> newName). Iterate ALL zoneconfigs: for each entry in `.ZoneNames`, if `zoneRenameMap[entry]` exists, replace with the new name.

**Step 2e: Assign rebuilt maps back to cfg.**
```go
cfg.Aliases = newAliases
cfg.Zones = newZones
cfg.ZoneConfigs = newZoneConfigs
return cfg
```

**Warning format:** Use `%q` for quoting names (matches existing parser convention). Use `%v` for printing slice of originals in collision warnings.
