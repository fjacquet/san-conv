**Test cases to include (build ALL IR inline — no fixture files):**

**SANI-01 (truncation):**
- "alias name exceeding 63 chars is truncated with warning": Create an alias with name `strings.Repeat("A", 70)`. Assert: alias exists in output map with key `strings.Repeat("A", 63)`, alias `.Name` equals `strings.Repeat("A", 63)`, `len(out.Warnings) >= 1`, at least one warning contains `"truncated"`.
- "zone name exceeding 63 chars is truncated with warning": Create a zone with name `strings.Repeat("Z", 70)` at VSAN 0 (Brocade-style, key = name). Assert: zone exists with truncated 63-char key, `.Name` is 63 chars, warning contains `"truncated"`.
- "name exactly 63 chars is not truncated": Create alias with `strings.Repeat("B", 63)`. Assert: no warnings, alias key unchanged.

**SANI-02 (char replacement):**
- "hyphen replaced with underscore in pre-8.1 mode": Create alias named `"Server-HBA-A"` with fosVersion `"pre-8.1"`. Assert: alias key is `"Server_HBA_A"`, alias `.Name` is `"Server_HBA_A"`, warning contains alias name and mentions replacement.
- "dollar and caret replaced in pre-8.1 mode": Create alias named `"Host$Port^1"`. Assert: alias key is `"Host_Port_1"`, warning emitted.
- "hyphen permitted in 8.1+ mode": Create alias named `"Server-HBA-A"` with fosVersion `"8.1+"`. Assert: alias key is `"Server-HBA-A"` (unchanged), zero warnings.
- "dollar and caret permitted in 8.1+ mode": Create alias named `"Host$Port^1"` with fosVersion `"8.1+"`. Assert: alias key unchanged, zero warnings.
- "at-sign replaced in both modes": Create alias named `"Host@Domain"` with fosVersion `"8.1+"`. Assert: alias key is `"Host_Domain"`, warning emitted. (@ is not in either allowed charset.)

**SANI-03 (collision detection):**
- "two aliases colliding after char replacement are disambiguated": Create two aliases `"A-B"` and `"A_B"` in pre-8.1 mode. Both sanitize to `"A_B"`. Assert: output has two distinct alias keys (one is `"A_B"`, other is `"A_B_2"`), warning contains `"collision"`, both aliases have different `.Name` values.
- "two zones colliding after truncation are disambiguated": Create two zones with names that share a 63-char prefix but differ at char 64+. Both truncate to the same 63 chars. Assert: two distinct zone keys, one gets `_2` suffix, collision warning emitted.
- "collision suffix does not exceed 63 chars": Create two aliases that sanitize to the same 63-char name. The `_2` suffix must not make the result 65 chars. Assert: both resulting alias names are <= 63 chars.

**Cross-reference updates:**
- "zone member alias value updated when alias renamed": Create alias `"A-host"` and zone with member `{Type: "alias", Value: "A-host"}` in pre-8.1 mode. Assert: after sanitization, zone member value is `"A_host"` (matching the sanitized alias name).
- "zoneset zone name updated when zone renamed": Create zone `"My-Zone"` and zoneset with `ZoneNames: []string{"My-Zone"}` in pre-8.1 mode. Assert: after sanitization, zoneset's `ZoneNames[0]` is `"My_Zone"`.

**MDS composite key handling:**
- "MDS zone composite key reconstructed after rename": Create IR with `SourceFormat: "mds-nxos"`, zone keyed as `"My-Zone@vsan10"` with `Name: "My-Zone"`, `VSAN: 10`. In pre-8.1 mode. Assert: new key is `"My_Zone@vsan10"`, zone `.Name` is `"My_Zone"`.

**No-op case:**
- "clean names produce no warnings": Create alias `"CleanName_1"`, zone `"CleanZone_2"`, zoneset with that zone. FOS pre-8.1. Assert: zero warnings, all names unchanged.

Each test case must build the `*ir.ZoningConfig` inline using map literals. Helper functions are allowed for reducing boilerplate (e.g., `makeAlias(name, pwwn string) *ir.Alias`).

Use `require` (not `assert`) for all assertions per CLAUDE.md convention.
