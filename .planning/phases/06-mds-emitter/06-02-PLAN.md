    **Function signature:** `func Emit(cfg *ir.ZoningConfig, w io.Writer) error` (2 params, no scriptMode).

    **Imports:** `"fmt"`, `"io"`, `"sort"`, `"github.com/fjacquet/san-conv/internal/ir"`.

    **Implementation — follow the research skeleton from 06-RESEARCH.md exactly:**

    1. Define `const defaultVSAN = 1` at the top of Emit().

    2. **Aliases section (CONV-04):**
       - `aliasKeys := sortedStringKeys(cfg.Aliases)`
       - If aliases exist: emit `device-alias database\n`
       - For each key: `alias := cfg.Aliases[key]`, emit `  device-alias name %s pwwn %s\n` (2-space indent, use `alias.Name` and `alias.PWWN`)
       - Emit `device-alias commit\n` then blank line

    3. **Zones section (CONV-05):**
       - `emittedZones := make(map[string]bool)` to track which zones were actually written
       - `zoneKeys := sortedStringKeys(cfg.Zones)`
       - For each key: `zone := cfg.Zones[key]`
       - Resolve VSAN: `vsan := zone.VSAN; if vsan == 0 { vsan = defaultVSAN }`
       - Filter members: check if any non-unsupported members exist
       - If no valid members: append warning `zone %q has no valid NX-OS members after filtering unsupported types -- skipped` to `cfg.Warnings`, continue
       - Emit `zone name %s vsan %d\n` using `zone.Name` (NOT the map key) and resolved vsan
       - For each member: if `m.Type == "alias"` emit `  member device-alias %s\n`; if `m.Type == "pwwn"` emit `  member pwwn %s\n`; skip unsupported silently
       - Emit blank line after zone block
       - Set `emittedZones[zone.Name] = true`

    4. **ZoneConfigs section (CONV-06, OUT-03):**
       - `cfgKeys := sortedStringKeys(cfg.ZoneConfigs)`
       - For each key: `zc := cfg.ZoneConfigs[key]`
       - Resolve VSAN: `vsan := zc.VSAN; if vsan == 0 { vsan = defaultVSAN }`
       - Filter ZoneNames: only include names where `emittedZones[zoneName]` is true
       - If no filtered zone names: skip this zoneset
       - Emit `zoneset name %s vsan %d\n` using `zc.Name` and resolved vsan
       - For each filtered zone name: emit `  member %s\n`
       - Emit blank line
       - Emit `zoneset activate name %s vsan %d\n` using `zc.Name` and resolved vsan (this is a REAL command, NOT commented — unlike Brocade's cfgenable)
       - Emit blank line

    5. Return nil.

    6. **sortedStringKeys helper:** Copy the generic helper verbatim from brocade emitter:
       ```go
       func sortedStringKeys[V any](m map[string]V) []string {
           keys := make([]string, 0, len(m))
           for k := range m {
               keys = append(keys, k)
           }
           sort.Strings(keys)
           return keys
       }
       ```
       Each package gets its own unexported copy — no shared utility package.

    **Critical implementation details:**
    - Use `fmt.Fprintf(w, "  device-alias name %s pwwn %s\n", ...)` — literal 2-space prefix, NOT tab
    - Use `fmt.Fprintf(w, "  member device-alias %s\n", ...)` — literal 2-space prefix
    - Use `zone.Name` in ALL emitted commands — NEVER use the map key
    - The warning string for skipped zones must contain the zone name AND the word "skipped" (tests assert both)
    - `zoneset activate` is emitted as a real command — NEVER commented out (unlike Brocade cfgenable)
    - Use em-dash (--) in the warning string to match the research skeleton: `"skipped"` not `"— skipped"` — actually use ASCII double-dash `--` for safety; the test just checks for Contains "skipped"
