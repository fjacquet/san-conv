    ```go
    type Options struct {
        InputFile  string
        Direction  string
        OutputFile string
        ScriptFile string
        FOSVersion string
    }
    ```

    **Run function — exact implementation order:**

    1. Open InputFile with `os.Open`. On error return `fmt.Errorf("open %q: %w", opts.InputFile, err)`.
       Defer close.

    2. Parse based on Direction:
       - "mds2brocade" → `mdsparser.Parse(f)`
       - "brocade2mds" → `brocadeparser.Parse(f)`
       - other → `return fmt.Errorf("unknown direction %q (use mds2brocade or brocade2mds)", opts.Direction)`
       On parse error return `fmt.Errorf("parse: %w", err)`.

    3. Sanitize ONLY for mds2brocade direction:
       ```go
       if opts.Direction == "mds2brocade" {
           cfg = validator.Sanitize(cfg, opts.FOSVersion)
       }
       ```

    4. Resolve primary output writer:
       ```go
       primaryW := stdout
       if opts.OutputFile != "" {
           of, ferr := os.Create(opts.OutputFile)
           if ferr != nil {
               return fmt.Errorf("create output %q: %w", opts.OutputFile, ferr)
           }
           defer of.Close()
           primaryW = of
       }
       ```

    5. Emit primary output AND handle script file WITHOUT double-counting warnings:

       For mds2brocade:
       ```go
       if err := brocadeemitter.Emit(cfg, primaryW, false); err != nil {
           return fmt.Errorf("emit: %w", err)
       }
       // Script emit: snapshot warning count BEFORE second emit to avoid double warnings.
       if opts.ScriptFile != "" {
           warnCountBefore := len(cfg.Warnings)
           var scriptBuf bytes.Buffer
           if err := brocadeemitter.Emit(cfg, &scriptBuf, true); err != nil {
               return fmt.Errorf("emit script: %w", err)
           }
           // Trim any new warnings added by script emit (they duplicate plain emit warnings).
           cfg.Warnings = cfg.Warnings[:warnCountBefore]
           sf, serr := os.OpenFile(opts.ScriptFile, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, 0755)
           if serr != nil {
               return fmt.Errorf("create script %q: %w", opts.ScriptFile, serr)
           }
           defer sf.Close()
           if _, err := scriptBuf.WriteTo(sf); err != nil {
               return fmt.Errorf("write script: %w", err)
           }
       }
       ```

       For brocade2mds:
       ```go
       if err := mdsemitter.Emit(cfg, primaryW); err != nil {
           return fmt.Errorf("emit: %w", err)
       }
       ```

    6. Print warnings and summary to stderr — AFTER all emit calls:
       ```go
       for _, w := range cfg.Warnings {
           fmt.Fprintf(stderr, "WARN: %s\n", w)
       }
       fmt.Fprintf(stderr, "Summary: %d aliases, %d zones, %d configs converted; %d warnings\n",
           len(cfg.Aliases), len(cfg.Zones), len(cfg.ZoneConfigs), len(cfg.Warnings))
       ```

    7. Return nil.

    **Critical constraints:**
    - Do NOT call `os.Exit` anywhere in converter.go
    - Do NOT write to `os.Stdout` directly — always use the `stdout io.Writer` parameter
    - Use `zone.Name` field, never map keys, in any user-facing strings
    - `validator.Sanitize` is called ONLY when `opts.Direction == "mds2brocade"`
    - Script file MUST use `os.OpenFile(..., 0755)` not `os.Create` (executable permission)
