```go
package ir

type ZoningConfig struct {
    Aliases      map[string]*Alias      // key: alias name (pre-sanitization)
    Zones        map[string]*Zone       // key: "name@vsanN" for MDS multi-VSAN
    ZoneConfigs  map[string]*ZoneConfig // key: zoneset name
    SourceFormat string                 // "mds-nxos"
    Warnings     []string               // non-fatal issues; appended by parser
}

type Alias struct {
    Name string // original source name
    PWWN string // normalized lowercase colon-hex: "10:00:00:00:c9:12:34:56"
    VSAN int    // 0 = fabric-wide (device-alias); >0 = VSAN-scoped (fcalias)
}

type Zone struct {
    Name    string
    VSAN    int
    Members []*ZoneMember
}

type ZoneMember struct {
    Type  string // "pwwn" | "alias" | "unsupported"
    Value string // pWWN string | alias name | raw unsupported member string
}

type ZoneConfig struct {
    Name      string
    VSAN      int
    ZoneNames []string // ordered zone names in this zoneset
}
```

2. `Parse(r io.Reader) (*ir.ZoningConfig, error)` function:
   - Read all lines into `[]string` using `bufio.Scanner`
   - Initialize `cfg` with `SourceFormat: "mds-nxos"`, and all three maps non-nil
   - Call `pass1BuildAliases(lines, cfg)` — pass 1
   - Call `pass2BuildZones(lines, cfg)` — pass 2
   - Return `cfg, nil`

3. `pass1BuildAliases(lines []string, cfg *ir.ZoningConfig)` function:
   - States: `stateIdle`, `stateDeviceAliasDB`, `stateFcAlias`
   - Current-fcalias tracking: local `currentFcAlias *ir.Alias`
   - Line classification ORDER (critical — must check in this exact order):
     1. `reDeviceAliasCommit` → transition to `stateIdle` (BEFORE reDeviceAliasEntry)
     2. `reDeviceAliasDBHeader` → transition to `stateDeviceAliasDB`
     3. `reFcAliasHeader` → create Alias{Name, VSAN}, store in cfg.Aliases[name], set currentFcAlias, transition to `stateFcAlias`
     4. `isTopLevelKeyword(line)` when in a block state → transition to `stateIdle`
     5. In `stateDeviceAliasDB`: `reDeviceAliasEntry` → add Alias{VSAN:0} to cfg.Aliases
     6. In `stateFcAlias`: `reFcAliasMember` → set currentFcAlias.PWWN (first member only; fcalias has one pWWN)

4. `pass2BuildZones(lines []string, cfg *ir.ZoningConfig)` function:
   - States: `stateIdle`, `stateZone`, `stateZoneset`
   - Current-zone and current-zoneset tracking: local pointer variables
   - VSAN tracking: `seenVSANs map[int]bool` — when len(seenVSANs) == 2 on first new VSAN, append multi-VSAN warning
   - Line classification ORDER (critical):
     1. `reIVRZoneHeader` → append IVR warning, transition to `stateIdle` (skip IVR block)
     2. `reIVRZonesetHeader` → append IVR warning, transition to `stateIdle`
     3. `reZoneHeader` → create Zone, map key = `fmt.Sprintf("%s@vsan%d", name, vsan)`, transition to `stateZone`
     4. `reZonesetActivate` → mark ZoneConfig (if not tracked, store activate info; currently no Active field in IR — skip silently)
     5. `reZonesetHeader` → create ZoneConfig, transition to `stateZoneset`
     6. `isTopLevelKeyword(line)` → transition to `stateIdle`
     7. In `stateZone`: check unsupported patterns FIRST (interface, fcid, ip-address, symbolic-nodename, fwwn), then device-alias, fcalias, pwwn
     8. In `stateZoneset`: `reZonesetMember` → append to ZoneNames

   - Unsupported member handling: append warning `fmt.Sprintf("zone %q: unsupported member type %q (%s) skipped", zoneName, memberType, rawLine)` — do NOT add to zone.Members
   - Smart-zoning: detect `reMemberPWWNRole` AFTER extracting pWWN with `reMemberPWWN`; add ZoneMember{Type:"pwwn"} regardless; append warning only when role keyword present

5. `normalizeWWN(raw string) string` helper — from RESEARCH.md lines 469-481:
   - Remove colons, lowercase, reinsert colons every 2 hex chars
   - If compact length != 16, return `strings.ToLower(raw)` unchanged

6. `isTopLevelKeyword(line string) bool` helper — from RESEARCH.md lines 133-142:
   - Blank line or `!` comment → return false (stay in block)
   - No leading space/tab AND len > 0 → return true

**CRITICAL anti-patterns (do NOT do these):**

- Do NOT check `reZoneHeader` before `reIVRZoneHeader` — IVR lines contain "zone name" substring and will be mis-parsed
- Do NOT use package-level variables for parser state — use local variables inside pass1/pass2 functions
- Do NOT return an error for unrecognized lines — only return error for `scanner.Err()`
- Do NOT add a member to zone.Members for unsupported types — they are skipped entirely
- Do NOT forget to init all three maps in `Parse` before calling pass functions: `cfg.Aliases = make(map[string]*ir.Alias)` etc.
