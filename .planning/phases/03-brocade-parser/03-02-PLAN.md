// WWN normalizer:
func normalizeWWN(raw string) string {
    compact := strings.ReplaceAll(raw, ":", "")
    compact = strings.ToLower(compact)
    if len(compact) != 16 {
        return strings.ToLower(raw)
    }
    parts := make([]string, 8)
    for i := range 8 {
        parts[i] = compact[i*2 : i*2+2]
    }
    return strings.Join(parts, ":")
}

**Structure the file with these sections in order:**

**1. Package-level compiled regexps:**
```go
var (
    // cfgshow section boundaries
    reCfgshowSection   = regexp.MustCompile(`^Defined configuration:\s*$`)
    reCfgshowEffective = regexp.MustCompile(`^Effective configuration:\s*$`)

    // cfgshow type tokens (leading whitespace + keyword + name)
    reCfgToken   = regexp.MustCompile(`^\s+cfg:\s+(\S+)`)
    reZoneToken  = regexp.MustCompile(`^\s+zone:\s+(\S+)`)
    reAliasToken = regexp.MustCompile(`^\s+alias:\s+(\S+)`)

    // CLI format commands
    reAliCreate  = regexp.MustCompile(`^alicreate\s+"([^"]+)"\s*,\s*"([^"]+)"`)
    reZoneCreate = regexp.MustCompile(`^zonecreate\s+"([^"]+)"\s*,\s*"([^"]+)"`)
    reCfgCreate  = regexp.MustCompile(`^cfgcreate\s+"([^"]+)"\s*,\s*"([^"]+)"`)

    // CLI format detection (used by detectCLIFormat)
    reCLICommand = regexp.MustCompile(`^(alicreate|zonecreate|cfgcreate)\s+`)
)
```

**2. Exported `Parse` function:**
```go
func Parse(r io.Reader) (*ir.ZoningConfig, error)
```
- Read all lines with `bufio.NewScanner(r)` into a `[]string` slice (same as MDS parser)
- Check `scanner.Err()` for I/O errors (only error case)
- Initialize `cfg := &ir.ZoningConfig{SourceFormat: "brocade-fos", Aliases: make(map[string]*ir.Alias), Zones: make(map[string]*ir.Zone), ZoneConfigs: make(map[string]*ir.ZoneConfig)}`
- Call `detectCLIFormat(lines)`: if true, call `parseCLIFormat(lines, cfg)`; if false, call `parseCfgshowFormat(lines, cfg)`
- Return `cfg, nil`

**3. `detectCLIFormat(lines []string) bool`** (PARSE-09):
- Iterate lines. For each trimmed line:
  - If `trimmed == "Defined configuration:"` return false (cfgshow)
  - If `reCLICommand.MatchString(trimmed)` return true (CLI)
- Default return false (assume cfgshow if ambiguous)

**4. `parseCfgshowFormat(lines []string, cfg *ir.ZoningConfig)`** (PARSE-07):
- State machine with states: `stateIdle`, `stateInSection`, `stateCfg`, `stateZone`, `stateAlias`
- Track `inDefinedSection bool` -- becomes true on `Defined configuration:`, false on `Effective configuration:` or EOF
- When `inDefinedSection == false`, skip all lines
- Type token matching (only when NOT in continuation):
  - `reCfgToken` match: create `&ir.ZoneConfig{Name: name, VSAN: 0}`, store in `cfg.ZoneConfigs[name]`, set `currentCfg`, nil out `currentZone`/`currentAlias`, set state=stateCfg
  - `reZoneToken` match: create `&ir.Zone{Name: name, VSAN: 0}`, store in `cfg.Zones[name]` (plain name key, NOT "name@vsan0"), set `currentZone`, nil out `currentCfg`/`currentAlias`, set state=stateZone
  - `reAliasToken` match: create `&ir.Alias{Name: name, VSAN: 0}`, store in `cfg.Aliases[name]`, set `currentAlias`, nil out `currentCfg`/`currentZone`, set state=stateAlias
- Member line parsing (when inside a state): call `parseMemberLine(line)` which returns `(members []string, continues bool)`
  - In stateCfg: append members to `currentCfg.ZoneNames`
  - In stateZone: for each member, if `looksLikeWWN(member)` then append `&ir.ZoneMember{Type: "pwwn", Value: normalizeWWN(member)}`, else append `&ir.ZoneMember{Type: "alias", Value: member}`
  - In stateAlias: first member only becomes `currentAlias.PWWN = normalizeWWN(member)` (alias has exactly one pWWN)
- Continuation handling: track `continuation bool`. When `parseMemberLine` returns `continues=true`, set `continuation=true`. On next line, if `continuation==true`, do NOT check type tokens -- treat line as member data. Reset `continuation` based on the new line's backslash status.

**5. `parseCLIFormat(lines []string, cfg *ir.ZoningConfig)`** (PARSE-08):
- Iterate lines. For each trimmed line:
  - `reAliCreate` match: `name=m[1]`, `pwwn=normalizeWWN(m[2])`. Store `cfg.Aliases[name] = &ir.Alias{Name: name, PWWN: pwwn, VSAN: 0}`
  - `reZoneCreate` match: `name=m[1]`, member list=`m[2]`. Split member list on ";", trim each. For each member: if `looksLikeWWN(member)` then `Type: "pwwn", Value: normalizeWWN(member)`, else `Type: "alias", Value: member`. Store zone in `cfg.Zones[name]` with `VSAN: 0`.
  - `reCfgCreate` match: `name=m[1]`, zone list=`m[2]`. Split on ";", trim each. Store `cfg.ZoneConfigs[name] = &ir.ZoneConfig{Name: name, VSAN: 0, ZoneNames: zoneNames}`
  - Lines not matching any pattern: silently skip (same behavior as MDS parser for unrecognized lines)

**6. Helper functions:**

`parseMemberLine(line string) (members []string, continues bool)`:
- `trimmed := strings.TrimSpace(line)`
- If `strings.HasSuffix(trimmed, "\\")`: set `continues = true`, `trimmed = strings.TrimSuffix(trimmed, "\\")`, `trimmed = strings.TrimSpace(trimmed)`
- Split `trimmed` on ";", TrimSpace each part, skip empty strings
- Return members, continues

`looksLikeWWN(s string) bool`:
- Return `strings.Contains(s, ":")` -- Brocade alias names cannot contain colons per FOS charset rules

`normalizeWWN(raw string) string`:
- Copy exactly from MDS parser: strip colons, lowercase, check len==16, re-join with colons in 8 pairs
- This is a local copy (not shared package) per project convention -- IR package has zero imports

**Key constraints (non-negotiable):**
- Zone map keys are plain names (e.g., "fabric_zone1"), NOT "fabric_zone1@vsan0" -- per research decision and IR convention for Brocade
- All VSAN fields set to 0 -- Brocade has no VSAN concept
- SourceFormat is "brocade-fos" (not "brocade" or "fos")
- Parse only returns error for I/O failures (scanner.Err()), never for parse failures -- warn and continue pattern
- Use `require` in tests, not `assert`
